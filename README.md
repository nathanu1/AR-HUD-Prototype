# AR-HUD-Prototype
Interactive AR HUD prototype for exploring optical display constraints, information density, latency, and wearable interface design.

## Live Demo
[Open the AR HUD Prototype] https://nathanu1.github.io/AR-HUD-Prototype/

Interface Experiment:
- field of view
- display dimensions
- focal length
- information density
- ambient brightness
- head-locked and world-locked interfaces
- motion-to-photon latency
- navigation overlays
- telemetry displays
- notifications

## Motivation

Wearable interfaces must present useful information without obstructing the user's environment or overwhelming their attention.
This prototype provides a way to explore those interaction tradeoffs before integrating the interface with a larger real-time perception system.
